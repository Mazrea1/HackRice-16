# HackRice-16
A webapp that assists users in creating workout plans and offering alternatives when equipment is being used up.

Data:
Will be in it's own folder which will contain information listed as

1. ID
2. Name
3. Muscle_group
4. is_machine
5. Equipment_needed
6. Instructions
7. Image_URL
8. Swap_ID

Logic:
Use algorithms and to search for the different excerises and store workouts to create a workout plan

Presentation Layer:
Consists of the main/app file, frontend files, and event listeners etc.
